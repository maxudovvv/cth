# public/media/approved/

**Only** media that is fully cleared belongs here: confirmed owner, granted publication permission, consent for identifiable people, caption + credit + date, cultural review passed, and organizational approval. Media in this folder is eligible to appear on the site.

Each file must have a matching entry in `content/media-manifest.example.json` (copied to `media-manifest.json` in real use) with `publicationStatus: "approved"`.

Nothing from social media (including Facebook) may be placed here without explicit permission and originals. See `docs/media-workflow.md`.
