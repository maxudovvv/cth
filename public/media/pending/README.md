# public/media/pending/

Holding area for media that is **under review** — awaiting ownership confirmation, permission, captions, consent, or cultural review.

**Media here is NOT production-eligible.** This folder is git-ignored (see `.gitignore`) so pending material is never committed or shipped. The application must never read images from this folder. Move an item to `../approved/` only after it fully clears review (see `docs/media-workflow.md`).

Do not place scraped or downloaded social-media content here. Obtain originals and permission from the organization first.
