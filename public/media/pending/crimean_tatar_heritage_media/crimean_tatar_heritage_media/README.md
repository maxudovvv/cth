# Crimean Tatar Heritage Canada — Media Pack

This archive contains the photos supplied in the chat, organized for initial website integration.

Folders:
- `community-events/` — community, outdoor, Toronto, flag, and event photography.
- `heritage-textiles/` — embroidery, ornaments, textiles, and traditional clothing.
- `history-memory/` — historical portraits and Sürgünlik/survivor-story graphics.
- `official-archive/` — conference, podium, and advocacy-adjacent material; keep off the public homepage unless explicitly approved.

Important:
- Treat all files as `permissionStatus: pending` until publication rights, photographer credit, names, dates, and captions are confirmed.
- Do not use unidentified historical portraits with guessed names.
- Several small square images are suitable for cards and galleries, not full-screen hero backgrounds.
- Duplicate copies from the chat were removed from the archive.
