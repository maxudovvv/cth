# Gallery experiment source

The GSAP loop, reveal, and Flip transition modules in
`src/components/gallery/codrops/` are adapted from Surya Aditya's
[Codrops Infinite Scroll Gallery and Flip Transitions](https://github.com/surya-aditya/codrops-infinite-scroll-and-content-transition),
commit `1ed1cf5ff901054c7bd943ba27fafb6f5653b5f9`.

The upstream `package.json` identifies the example as ISC licensed. The
example's README links to an MIT license file that is currently absent from
the repository. The experiment uses CTH's own photographs and descriptions;
none of the example photographs or cultural copy are included.
