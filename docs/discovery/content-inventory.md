# Content Inventory — Crimean Tatar Heritage Canada

> Status: **template — to be populated during discovery.** This is the working catalogue of everything that might appear on the website. Nothing here is approved for publication until it clears the tracking columns below and is recorded in `content-source-register.md`. Do not invent entries; leave cells blank or mark "unknown".

## How to use this

Each section has a table. For **every** content item, track these columns (abbreviated in tables as noted):

| Column | Values |
| --- | --- |
| Owner | Who holds/controls it |
| Source | Where it comes from |
| Copyright | org-owned · third-party · public-domain · unknown |
| Permission | none · requested · granted · denied · n/a |
| Verified (facts) | verified · requires-source · n/a |
| Cultural review | pending · reviewed · not-required |
| Translation | n/a · needed · in-progress · complete |
| Image quality | n/a · low · ok · high |
| Publication ready | no · needs-work · yes |
| Website section | intended destination |

> Shorthand header used in tables below: **Own | Src | © | Perm | Fact | Cult | Transl | Qual | Ready | Section**
