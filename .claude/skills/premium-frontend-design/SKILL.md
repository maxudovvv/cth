# premium-frontend-design

Turns intent into refined, maintainable, editorial interfaces. Complements `ui-ux-pro-max` (which sets the quality bar) with the craft of composition and component design.

## Responsibilities

- Develop refined layouts with a clear compositional idea, not default stacks.
- Establish and maintain visual hierarchy through type scale, weight, space, and contrast.
- Build expressive **but maintainable** components with sensible props and variants.
- Use **editorial composition** — asymmetry, feature/detail relationships, pull quotes, captions — instead of repetitive card grids.
- Combine light and dark sections deliberately, with intentional transitions between them.
- Define responsive behavior for every layout (mobile-first, then enhance).
- Maintain visual consistency via shared tokens and spacing scales.
- Avoid template-driven design.
- Design components for **real content** (variable-length titles, long translated strings, real photographs) rather than placeholder text.
- Support progressive enhancement: the layout is legible and usable before scripts and effects load.

## Encouraged techniques

- Strong, characterful typography with a clear scale.
- Layered editorial layouts with intentional overlap and depth cues.
- Meaningful negative space that gives content room to breathe.
- Culturally grounded visual motifs (drawn from authentic Crimean Tatar references — coordinate with `cultural-brand-director`).
- Subtle depth — restrained shadows, layering, and texture, not heavy glassmorphism.
- High-quality image presentation: correct aspect ratios, art-directed crops, captions, credits.
- Deliberate asymmetry where it improves rhythm and focus.
- Restrained visual effects that serve content.

## Constraints

- No generic SaaS or nonprofit-template patterns.
- No repeated identical-card grids as a default layout.
- No decorative gradients, excessive rounding, or effects without purpose.
- Components must degrade gracefully with longer translated text and missing media.
- Every layout must have a defined mobile behavior before it is considered done.

## Definition of good

A section reads as authored and specific: you could not swap it into an unrelated website without it looking wrong. It holds up with real content, on a phone, and for an older reader. Reviewed with `ui-ux-pro-max` and `cultural-brand-director` before completion.
