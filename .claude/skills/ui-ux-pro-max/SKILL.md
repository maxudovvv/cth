# ui-ux-pro-max

The interface-quality authority for this project. Every page is part of **one coherent, museum-quality cultural experience** — never a collection of unrelated sections. This skill gates interface work: nothing ships without passing its review.

## When to use

- Before starting any page or component (set the bar).
- While building (make decisions against these principles).
- Before marking any interface work done (run the pre-approval checklist).

## Responsibilities — enforce

- Premium, **intentional** UI where every element has a reason to exist.
- Excellent information hierarchy and museum-quality digital storytelling.
- User-centered UX and a mobile-first responsive foundation.
- Coherent spacing and visual rhythm from a shared scale.
- Accessible navigation, readable typography, clear calls to action.
- Useful **hover, focus, active, loading, empty, success, and error** states for every interactive element.
- Usability for **older community members**: larger tap targets, generous text sizes, plain labels.
- Keyboard accessibility and touch-friendly controls.
- Comfortable reading widths (~60–75 characters) and strong contrast.
- Predictable, consistent interaction behavior across the site.
- Clear multilingual navigation and language switching.
- Reduced cognitive load; consistent component behavior.
- A visual and UX review **before** the work is considered complete.

## Prohibited — never produce

- Generic AI-generated SaaS layouts.
- Repetitive grids of identical cards.
- Excessive rounded rectangles.
- Excessive glassmorphism.
- Random or decorative gradients.
- Decorative effects without cultural or functional purpose.
- Oversized empty hero sections.
- Tiny, low-contrast text.
- Animation that delays access to content.
- Desktop-only experiences.
- Visual novelty that harms usability.
- Treating every section as an isolated design.

## Core principle

Treat every page as one chapter of a single museum-quality cultural experience. Composition, typography, color, and motion should feel authored by one hand and grounded in authentic Crimean Tatar culture — never a template applied section by section.

## Pre-approval checklist (all must pass)

Before approving a page, verify:

1. Is the page purpose understandable within **five seconds**?
2. Is the hierarchy clear?
3. Is the most important content immediately discoverable?
4. Is the page comfortable for **older visitors**?
5. Does it work naturally on **mobile**?
6. Is the next useful action clear?
7. Does it represent Crimean Tatar culture **respectfully**?
8. Does it avoid generic AI-template aesthetics?
9. Is the page **keyboard-accessible**?
10. Are animations purposeful and restrained?
11. Does the page load **progressively** (content first)?
12. Does the design remain usable with **longer translated text**?

Record the result of each item. If any fails, the work is not done — fix or escalate. Use `verified` / `not run` / `blocked` / `passed with warnings` / `failed` when reporting.

## Working relationships
